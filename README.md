# דובי קורא — dovi-reading

מערכת לימוד קריאה בניקוד, לילדים ולמבוגרים. React + Vite + Supabase.

## משתמשים
כל משתמש נרשם עם שם, קוד אישי והגייה (אשכנזית: קמץ o, חולם oy, צירה ey; או רגילה).
לכל משתמש קבוצות, הקלטות, התקדמות וכוכבים משלו; משתמש חדש מקבל עותק של הקבוצות של דובי.
האפליקציה שולחת `x-user-id` ו-`x-user-code` בכל בקשה, ו-`current_user_id()` במדיניות ה-RLS בודקת אותם.
במכשיר אחד אפשר לשמור כמה משתמשים (מסך "מי קורא?").

## הרצה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה ל-dist/
```

פרטי ה-Supabase (URL + publishable key) נמצאים ב-`.env`. המפתח הזה ציבורי מעצם הגדרתו; ההרשאות נאכפות ב-RLS.
בלי המשתנים האלה המשחקים עדיין עובדים, רק לא שומרים התקדמות.

## משחקים

| משחק | מה עושים |
|------|----------|
| 👂 שמע ובחר | שומעים הברה (או מילה מקבוצה) ובוחרים איך היא כתובה |
| 🗣️ קרא בקול | רואים הברה/מילה/שורה, לוחצים ומחזיקים 🎤 וקוראים; 🐢 מקריא הברה-הברה עם הדגשה |
| 🚂 רכבת ההברות | מיקרופון פתוח כל הזמן; הקרון המואר מתחלף לירוק כשאומרים אותו, ואדום כשטועים |
| 🧩 בנה מילה | שומעים מילה ומסדרים את ההברות שלה; הן מתחברות והמילה נקראת |
| 🔍 אותיות דומות | שומעים שם של אות ומוצאים אותה בין דומות (ב כ פ, ד ר, ה ח ת…) |
| ✅ האות הנכונה | שומעים שם של אות ומוצאים את הנכונה בין הפוכות, שבורות ומקושטות |
| 📖 קריאת טקסט | טקסט משלך (תפילה למשל): הצגה אוטומטית עם הדגשה בקצב נבחר, או קריאה בקול שורה אחרי שורה |
| ⚡ קריאה ברצף | המילים מופיעות בזו אחר זו במקום אחד, בקצב של 10–600 מילים בדקה (מילה, שתיים, שלוש או הברה־הברה). בסוף כל תרגול מדרגים איך היה, ואפשר לשמור את הטקסט והקצב להמשך. אפשרויות: ניקוד, הגברה הדרגתית, אות מרכזית צבועה, והדגשת ההברה האחרונה (רק בהגייה רגילה, כבויה כברירת מחדל; בהגייה אשכנזית אין הדגשה) |

לפני משחק של הברות/קבוצות בוחרים תוכן: הברות בודדות (ובוחרים ניקוד: פתח/חיריק/קמץ, ואפשר גם סגול, צירה,
חולם, קובוץ, שורוק) או קבוצה, וכמה סיבובים (5 / 10 / הכל). משחק קצר על קבוצה ארוכה ממשיך מהמקום שבו נעצר.

## המסע

כל ⭐ מתקדם במסע: תחנה כל 10 כוכבים, 22 תחנות עד 🕍. החיה של כל תחנה מצטרפת להליכה (לוחצים עליה והיא אומרת את שמה).
המסע מושתת על סך הכוכבים של המשתמש, בכל המשחקים.

## אפליקציה ובלי חיבור

אפשר להתקין ("הוספה למסך הבית"). האפליקציה והאודיו של שמות האותיות נשמרים במכשיר; רשימות הקבוצות והטקסטים נשמרים
כעותק אחרון לשימוש בלי חיבור. הקלטות, התקדמות וכוכבים דורשים חיבור.

### בחירת תוכן לפני כל משחק
לפני שמתחילים בוחרים: **הברות בודדות** (ובוחרים איזה ניקוד — פתח/קמץ/חיריק, אחד או יותר) או **קבוצה** מההגדרות.
הבחירה האחרונה נשמרת במכשיר. אחרי סבב של 80% ומעלה בקבוצה — "לקבוצה הבאה" מתחיל מיד את הקבוצה שאחריה.

### משחק 1 — שמע ובחר
בקבוצה: המילים לפי הסדר, כל אחת מול שתי המילים הדומות לה ביותר בקבוצה.
בהברות בודדות: 10 סיבובים. בכל סיבוב נשמעת הברה ומוצגות 3 אפשרויות: התשובה, אותה אות עם ניקוד אחר, ואות דומה (ב/כ/פ, ד/ר, ה/ח/ת…).
הברות שדובי טועה בהן חוזרות יותר (לפי טבלת `progress`). בטעות — נשמעת ההברה שבחר ואחריה הנכונה.

### משחק 2 — קרא בקול
דובי רואה הברה או מילה, יכול לשמוע אותה ב-🔊, **לוחץ ומחזיק** 🎤 בזמן שהוא קורא ועוזב כשסיים
(טבעת סביב הכפתור מתמלאת עד 8 שניות; הכפתור נהיה ירוק כשהמיקרופון באמת מקשיב). זיהוי הקול של הדפדפן (Chrome/Edge/Android)
כותב מה שמע, וההשוואה נעשית לפי ההגייה האשכנזית (קמץ = "o", ת בלי דגש = "s").
אחרי כל ניסיון אפשר לשמוע את עצמו ▶ ואת ההגייה הנכונה. אם הזיהוי טעה — "הורה: הוא אמר נכון ✓".
בדפדפן בלי זיהוי קול (Firefox) ההורה מסמן ✓/✗; גם אחרי פעמיים שהזיהוי לא שמע כלום.
בטלפונים וב-Safari לא מקליטים את הילד במקביל לזיהוי (שניהם צריכים את המיקרופון, והזיהוי מפסיד) —
"▶ אני" זמין רק במחשב (Chrome/Edge).
מילה אמיתית שהזיהוי כותב בכתיב הרגיל ("שלום") מתקבלת גם אם נאמרה באשכנזית, כי המנוע "מתקן" אותה בעצמו.

## הגדרות (⚙️ במסך הבית)

מוגנות ב**קוד הורה** (לפחות 6 תווים; נקבע בכניסה הראשונה). הקוד נבדק בשרת: בלעדיו אי אפשר לשנות תוכן.

- **קבוצות מילים** — רשימות של הברות/מילים עם ניקוד, שורה לכל פריט, בסדר שבו ישחקו. יש מקלדת ניקוד.
  המשחקים משתמשים בקבוצה הנוכחית ⭐; אחרי סבב של 80% ומעלה מופיע "לקבוצה הבאה".
  לכל מילה אפשר להקליט הגייה שלמה.
- **הקלטות הברות** — טבלת אות × ניקוד. הקלטה מחליפה את הקול הממוחשב בכל המשחקים,
  ומילה שכל ההברות שלה מוקלטות מושמעת כחיבור של ההקלטות.
- **עידוד** — משפטי עידוד מוקלטים שיושמעו באקראי אחרי תשובה נכונה.
- **קוד הורה** — החלפה ונעילה.

## כוכבים וחיות

כל תשובה נכונה בניסיון הראשון = ⭐. השורה הקבועה למעלה מראה את סך הכוכבים, 10 משבצות שמתמלאות,
וצללית של החיה הבאה. כל 10 כוכבים = חיה חדשה (עם קונפטי ושם החיה בקול). במסך הבית — האוסף.
הכוכבים נשמרים ב-`users.stars` (פונקציה `add_stars`).

המסכים של הילד בנויים מתמונות וסמלים במקום מילים (👂 ⬅ 👆, 🤩/🤔, 🔁, ⬅, 🏠, ⏭️);
במשחק 2 ההסבר נאמר בקול בפעם הראשונה. הטקסטים שנשארו מיועדים להורה.

## צלילים

צלילי המשוב מסונתזים בדפדפן (Web Audio): פעמונים עולים + ניצוצות לתשובה נכונה, "בלופ" רך לטעות
(לא זמזם), ופנפרה בסוף משחק — יחד עם קונפטי.

## שפת הממשק

עברית או רוסית (נבחרת בכניסה ובפרופיל, נשמרת למשתמש). הלימוד עצמו תמיד בעברית. הטקסטים בקוד כתובים בעברית ומשמשים כמפתח
ל-`t()`; התרגום לרוסית ב-`src/lib/ru.ts`. `node scripts/check-i18n.mjs` נכשל אם חסר תרגום.

## הקלטה מהירה

בהגדרות ← הקלטות הברות ← ⚡ הקלטה מהירה: מופיעה הברה, לוחצים על 🎤 ומחזיקים, אומרים, עוזבים — נשמר ועוברים להבאה
(רק הברות שעוד לא הוקלטו, לפי הניקוד שנבחר). כל הקלטה של הברה או מילה נחתכת משתיקות בהתחלה ובסוף ונשמרת כ-WAV קטן.

## אודיו

- `public/audio/letters/א.mp3…` — שמות האותיות (חסרה הקלטה ל-ץ).
- הקלטות מההגדרות נשמרות ב-Supabase Storage (bucket `audio`) וקודמות לכל השאר.
- `public/audio/syllables/{letter}_{nikud}.mp3` — הקלטות הברות, למשל `bet_patach.mp3`, `alef_kamatz.mp3`.
  שמות האותיות באנגלית: עמודת `key` בטבלת `letters` / בקובץ `src/data/hebrew.ts`.
  כל הברה שאין לה קובץ מושמעת ב-Web Speech API. כדי שקמץ יישמע "o" (אשכנזית), המנוע מקבל חולם במקום קמץ.

## בסיס נתונים

פרויקט Supabase: `dovi-reading` (`actdasahwnbwcputxgiz`, eu-central-1). ה-migrations ב-`supabase/migrations/`:

- `letters`, `nikud`, `recordings`, `words` — נתוני ייחוס, קריאה בלבד.
- `word_groups` + `words` — קבוצות המילים; `users.current_group_id` — הקבוצה הנוכחית.
- `praise_clips` — הקלטות עידוד.
- `users`, `game_sessions`, `progress` — נתוני הלומד. המשחק כותב אותם בלי קוד.
- שינוי תוכן (קבוצות, מילים, הקלטות, קבצים) דורש את קוד ההורה, שנשלח בכותרת `x-parent-code`
  ונבדק מול hash ב-`app_private.parent_pin` (פונקציה `is_parent()` במדיניות ה-RLS).
- `record_answer(user, letter, nikud, correct)` — עדכון התקדמות אטומי.
